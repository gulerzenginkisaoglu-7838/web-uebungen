# Web-Übungen  
 
Interaktive HTML/JS-Lernmaterialien und ein React-Tool, erstellt im Rahmen der Umschulung zum Fachinformatiker Systemintegration (GFN).  
 
## Inhalt  
 
- **index.html** — Quiz-Portal (Übersichtsseite mit Links zu den einzelnen Quiz-Tools)  
- **IPv4_Quiz.html** — Interaktives IPv4-Subnetting-Quiz  
- **LF09_Quiz_W1.html** — Netzwerktechnik-Quiz (LF09, Woche 1)  
- **zzahlenquiz 1.html** — Zahlensysteme-Quiz  
- **IT_Grundschutz_Lernkarten.html** — Lernkarten-Tool zu IT-Grundschutz  
- **FISI_BaWue_Lernhilfe.jsx** — React-Komponente zur AP1/AP2-Prüfungsvorbereitung (Hinweis: benötigt eine React-Umgebung wie Vite oder Create React App, lässt sich nicht direkt im Browser öffnen)  
 
## Nutzung  
 
Die HTML-Dateien können direkt im Browser geöffnet werden (z. B. über index.html als Startpunkt).
